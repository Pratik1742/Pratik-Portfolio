# Pratik Bhoskar - Angular Portfolio

Recruiter-focused personal portfolio built with Angular, SCSS, Bootstrap 5 and Bootstrap Icons.

## Requirements

- Node.js 20+ recommended
- npm

## Run locally

```bash
npm install
npm start
```

Open:

http://localhost:4200

## Production build

```bash
npm run build
```

## Before publishing

Update these placeholders:
- `your-email@example.com`
- GitHub URL
- Resume PDF in `src/assets/resume/`
- Any project screenshots/GitHub links you want to add

## Main sections

- Home
- About
- Skills
- Experience
- Projects
- Education
- Contact

CM Resident Hub is presented as the featured project with a technical architecture flow.
